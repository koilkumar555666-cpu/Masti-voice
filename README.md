# Masti Voice

An Android voice changer, sound effects board, and audio studio built with Kotlin and Jetpack Compose.

## Features

- **Voice Studio**: Record your voice with live visual waveform and transform it instantly using real-time DSP effects:
  - 🐿️ **Chipmunk**: High-pitch cute squeaky voice
  - 🎈 **Helium Gas**: Ultra-high balloon squeak
  - 👹 **Monster**: Booming deep pitch
  - 🗿 **Deep Giant**: Sub-bass rumble
  - 🤖 **Cyber Robot**: Metallic ring-modulated synthesis
  - 👽 **Alien Martian**: Sci-fi vibrato modulation
  - 📻 **Walkie Talkie**: Lo-fi bandpass radio filter with subtle crunch
  - 📢 **Megaphone**: Saturated overdrive loudspeaker effect
  - 🏔️ **Echo Cave**: Canyon delay repeats
  - ⏪ **Reverse Voice**: Plays audio backwards
  - 🐢 **Slow Motion**: Deep slow-drag effect
  - ⚡ **Turbo Rush**: Fast-forward speed rush
  - 👻 **Spooky Ghost**: Haunting eerie resonance
  - 🎛️ **Custom Pitch & Speed Tuner**: Sliders for custom pitch, speed/tempo, and echo
- **Instant Masti Soundboard**: Instantaneous sound effects:
  - 📢 Air Horn
  - 🔫 Laser Zap
  - 🦘 Cartoon Boing
  - 🍌 Slide Whistle
  - 🥁 Dramatic Thud
  - 🥳 Victory Chime
  - 👏 Cheering Crowd
  - 😂 Funny Laugh
- **Studio Library**:
  - Save modified voice recordings in high-fidelity 16-bit PCM WAV format
  - In-app playback with progress tracking
  - Share recordings via standard Android Share Sheet
  - Rename and delete saved tracks

## Tech Stack

- **Platform**: Android (Kotlin, Jetpack Compose, Material 3)
- **Audio Engine**: Android AudioRecord & AudioTrack PCM processing
- **Build System**: Gradle 9.3.1 with AGP 9.1.1, JDK 21
